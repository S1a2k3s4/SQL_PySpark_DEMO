# SQL, NumPy, Pandas & PySpark Practice

## Project Overview

This repository contains my hands-on practice in SQL, NumPy, Pandas, and PySpark using Jupyter Notebook and Databricks.

The goal of this repository is to strengthen my Data Engineering skills by implementing practical examples covering data manipulation, SQL queries, joins, file operations, and PySpark DataFrame transformations.
